Запуск в Windows
1. Распакуйте всю папку, не отделяя assets от desktop.py.
2. Откройте START_AFINA.cmd. Нужен Python с tkinter 3.12 или новее.
3. «Авторизация / войти снова» → используйте сохранённую авторизацию.
   Вводить Client ID каждый раз не нужно. Сохранение использует прежнее
   Windows Credential Manager, без переноса токена и пароля в файлы.
4. Укажите понедельник (ГГГГ-ММ-ДД) или нажмите «Прошлая неделя».
5. «Получить отчёт» → подтвердите нужный кабинет в том же окне.

Что работает
• Одно главное окно, локальная сова, карточки расхода/кликов/средней цены клика.
• Подтверждение кабинета, вход, ошибки и экспорт встроены в главное окно.
• Только системный браузер открывается отдельно для OAuth Яндекса.
• Таблица всех кампаний; диаграмма трёх крупнейших по расходу.
• Расходы с НДС, IncludeVAT=YES. Точные суммы в таблице/экспорте;
  итог без копеек вычисляется после сложения точных значений.
• Копирование таблицы (табуляция) и сохранение CSV UTF-8 для Excel.
• Повторный вход: сначала явное подтверждение удаления локального токена;
  после удаления отмена не восстанавливает прежний токен.
• Код можно вставить кнопкой, длина не ограничена семью цифрами.

Границы
• Это клиент чтения отчётов, не система управления рекламой.
• Биддинг, ключевые слова и баннеры явно помечены «Планируется».
• Роль аккаунта read-only НЕ подтверждается: программа просто вызывает
  только Clients.get и Reports API. Нет вызовов изменения рекламы.
• Нет автоматического обновления фоновых данных.
  Общие посетители Метрики доступны в отдельной вкладке.
• Прошлая неделя вычисляется по локальной дате компьютера.
• Закрытие окна во время запроса не изменяет рекламу; незавершённый
  запрос или обмен кода может быть прерван. Для повторного входа нужен новый код.
• Истёкший токен требует повторной авторизации. Refresh автоматически не используется.
• Прокси окружения намеренно не используются существующим HTTPS адаптером.

локальное поле Афины; секреты не входят в CSV и копируемый отчёт.
