АФИНА 2.1 · МЕТРИКА ТОЛЬКО ДЛЯ ЧТЕНИЯ
19.11.2026

Эта версия добавляет Метрику к работающему отчёту Директа.
Запуск тот же: START_AFINA.cmd или python desktop.py.
Безопасная проверка интерфейса: python desktop.py --demo.

ПЕРЕД ПЕРВЫМ ПОДКЛЮЧЕНИЕМ
Нужен Client ID OAuth-приложения, в регистрации которого разрешено
«Получение статистики, чтение параметров своих и доверенных счётчиков»
(metrika:read). По коду нельзя определить текущие разрешения регистрации
существующего приложения Афина. Регистрацию эта программа не меняет.
Можно использовать существующий Client ID, если metrika:read разрешён,
либо отдельное приложение Метрики. Не запрашивается metrika:write.
Аккаунт Яндекса должен иметь доступ к просмотру выбранных счётчиков.

ПОДКЛЮЧЕНИЕ
1. В главном окне выберите «Метрика · Посетители».
2. Укажите публичный Client ID приложения (не числовой ID счётчика).
3. «Подключить / войти снова»: подтвердите удаление только локального
   токена Метрики для этого ID. При первом входе удалять нечего.
4. В системном браузере войдите в нужный аккаунт и разрешите metrika:read.
5. Вставьте код из Яндекса в скрытое поле приложения, подтвердите.
Токен сохраняется отдельно в Windows Credential Manager под ключом
Afina/YandexMetrica/<Client ID>. Токен Директа не читается и не заменяется.
Публичный Client ID запоминается локально; пароли и токены в файлы не пишутся.
При следующих запусках вводить Client ID и входить заново не надо:
сразу запросите доступные счётчики или отчёт с сохранённой авторизацией.

НЕСКОЛЬКО СЧЁТЧИКОВ
Вставьте ID по строкам, через пробел, запятую или точку с запятой.
Повторы удаляются, порядок сохраняется. Нет ограничения 7/8/30 цифр.
Для защиты интерфейса ограничен общий ввод (16 КБ) и пакет (500 счётчиков).
Некорректный формат нужно исправить до запуска; он не уходит в API.
Можно получить список доступных счётчиков, выделить несколько (Ctrl/Shift)
и добавить их ID в поле. Ручные ID не обязаны присутствовать в этом списке:
их доступность проверяется отдельным запросом.

ОТЧЁТ
Выберите понедельник. Программа берёт неделю по воскресенье включительно,
в московском времени (UTC+03:00). Для каждого счётчика получает именно
ПОСЕТИТЕЛЕЙ: ym:s:users, не визиты и не просмотры.
Результаты разных счётчиков не суммируются.
Недоступные счётчики и ошибки показаны отдельными строками, НЕ нулём.
Кнопка остановки завершает текущий запрос и помечает оставшиеся как незапрошенные.
Сохраняются дата периода, sampled/sample_share и data_lag.
«Без семплирования» означает sampled=false, sample_share=1.
Это не обещание, что исторические данные больше никогда не изменятся.
Если признаки точности не предоставлены, точность не подтверждается.
CSV и копирование включают все результаты и статусы ошибок, без секретов.

ГРАНИЦЫ ЭТОЙ ВЕРСИИ
• Пока реализованы ОБЩИЕ посетители. Яндекс/Google/Директ/соцсети,
  URL «поли», массовое заполнение книги и недельное расписание сюда
  ещё не встроены. Для них нужно отдельное сопоставление отчётов и атрибуции.
• Раздел Метрики использует только GET для списка, информации счётчика
  и отчёта. Не создаёт/меняет счётчики, цели, доступы или рекламу.
• Нет автоматического refresh токена. При истечении выполните вход снова.
• Авторизация/ошибки/экспорт внутри того же окна; отдельно только браузер OAuth.
• Не закрывайте приложение во время сохранения авторизации: при прерывании
  состояние записи может быть не подтверждено. Прежний удалённый токен
  отменой не восстанавливается.

ПРОВЕРКА
Исходники и offline-тесты проверены. Все новые запросы в тестах подменены,
socket заблокирован. Реальные токены Метрики не читались, API не вызывался.
Живое подключение Метрики, визуальная проверка Windows и сопоставление
с данными браузера ещё требуются; для этого нужен разрешённый Client ID.

СОХРАНЕНИЕ СПИСКА СЧЁТЧИКОВ (2.1)
Кнопка «Сохранить счётчики» сохраняет только список числовых ID.
Список можно редактировать и сохранять повторно. При следующем открытии
Метрики он автоматически загружается. Чтобы сохранить пустой список,
удалите весь текст и нажмите эту кнопку: предустановки не вернутся.
В демо и рабочем режиме используется один и тот же публичный список,
сохранение списка не читает и не изменяет токены.

В публичной версии список изначально пуст. Добавьте ID собственных счётчиков.
При повреждённом файле показывается ошибка, исходный файл не меняется.

ЗАЩИТА ОТ КОНФЛИКТА (2.2)
Если другой экземпляр изменил список после его загрузки, сохранение
отклоняется. Ваш текст остаётся на экране. «Загрузить сохранённые» после
подтверждения заменяет поле актуальным списком; затем повторите правки.
Между экземплярами 2.2 запись сериализуется файлом блокировки. После
аварийного завершения оставшийся lock требует проверки; автоматически
удалять чужую активную блокировку приложение не будет. Закрывайте старые
версии 2.1 и ниже при редактировании списка: они не поддерживают блокировку.
